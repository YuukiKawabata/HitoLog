## Description

Wamoriは、親しい人だけで今日を交換するクローズドSNSです。

家族、パートナー、親友など、2〜5人の招待制グループ「輪」をつくり、1日1つの出来事や気持ちを残せます。公開タイムラインの速さから少し離れて、大切な人の今日を静かに知るための場所です。

主な機能:
・2〜5人の招待制グループ「輪」
・輪ごとに1日1つの非公開投稿
・日替わりのお題
・写真、コメント、3種類のリアクション
・輪のオーナー移譲とメンバー管理
・これまでの公開投稿を見られる「みんなの投稿」
・プロフィール、通知、ブロック、ミュート、通報
・アカウント削除

HitoLogをご利用いただいていた方のアカウント、投稿、フォロー、記事、支援、課金情報はそのまま引き継がれます。
